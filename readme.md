# 🎵 WaveTune — Music Player

WaveTune is a web-based music player built using HTML, CSS, and JavaScript. It features a modern interface with music playback controls, playlist navigation, search functionality, and settings.

## ✨ Features

- ▶️ Play and pause music
- ⏮️ Previous and next track controls
- 🎶 Playlist and song selection
- 🔍 Search for songs
- 🎧 Music categories
- 🔊 Volume control
- ⚙️ Settings section
- 📱 Responsive layout, if supported by the current implementation

## 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling and layout
- **JavaScript** — Playback controls and interactivity
- **Font Awesome** — Interface icons

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure the required music and image files are available.
4. Open `index.html` in your browser, or run it using the VS Code Live Server extension.

## 🎯 Project Objective

The objective of WaveTune is to develop an interactive music player while improving practical skills in frontend development, UI design, CSS layouts, and JavaScript event handling.
